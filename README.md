# Projeto Produção Agrícola no Brasil

Análise do setor agrícola (2015-2024), investigando produtividade, áreas de plantio, desempenho regional e impactos climáticos.

## Ferramentas Obrigatórias
- Python (Pandas)
- Streamlit
- Plotly
- Jupyter Notebook

## Como Executar
1. Instale as bibliotecas: `pip install -r requirements.txt`
2. Inicie a aplicação: `streamlit run app.py`
