## Sobre o Projeto
Este projeto consiste no desenvolvimento de uma aplicação analítica completa para investigar padrões de produção agrícola, produtividade por hectare, impacto de variáveis climáticas (volume de chuvas) e desempenho regional no Brasil entre os anos de 2015 e 2024.

## Estrutura do Repositório
* `app.py`: Código-fonte da aplicação interativa desenvolvida em Streamlit.
* `index.html`: Página web de apresentação do projeto (GitHub Pages).
* `requirements.txt`: Dependências e bibliotecas Python utilizadas.
* `dados/`: Pasta contendo a base de dados em formato CSV (`simulacao_producao_agricola_brasil.csv`).
* `notebooks/`: Contém o Jupyter Notebook (`analise_producao_agricola.ipynb`) com a análise exploratória e geração de gráficos.
* `database/` e `imagens/`: Pastas de suporte e estruturação do projeto.

## Tecnologias Utilizadas
* Python, Pandas, Matplotlib, Seaborn, Plotly, Streamlit, SQLAlchemy, SQLite, GitHub Pages.
