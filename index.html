Sobre o Projeto

Este projeto consiste no desenvolvimento de uma aplicação analítica completa para investigar padrões de produção agrícola, produtividade por hectare, impacto de variáveis climáticas (volume de chuvas e temperatura) e desempenho regional no Brasil entre os anos de 2015 e 2024.

Funcionalidades Desenvolvidas

  • Análise Exploratória Avançada: Tratamento de dados, remoção de duplicatas, tratamento de nulos e engenharia de atributos via Pandas e Jupyter Notebook.
  • Dashboard Interativo (Streamlit): Aplicação web estruturada com filtros múltiplos, KPIs dinâmicos, gráficos temporais e regionais.
  • Funcionalidades Avançadas: Persistência de dados utilizando SQLAlchemy/SQLite e consumo de API externa para contexto econômico.
  • Visualizações de Alta Qualidade: Gráficos dinâmicos gerados através de Plotly, Seaborn e Matplotlib.
